## kban
A simple self-hosted Kanban board application for planning and tracking tasks. Built with TypeScript, Next.js, and React, with data stored in a local PostgreSQL database.
<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/96919438-b6f4-45c9-9438-be220ac68738" />


```
make setup   # postgres, .env, npm install, prisma
make up      # start db + next dev
make down    # stop db
make db      # start postgres only
```
